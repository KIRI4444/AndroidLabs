# Playlist Maker — лабораторная работа 2

Приложение на Kotlin и Jetpack Compose по светлым макетам Figma. Сервер не нужен: треки и первые плейлисты взяты из локальных примеров.

## Как запустить

Открыть проект в Android Studio, дождаться загрузки зависимостей, выбрать эмулятор и нажать ▶ Run. Нужны JDK 21 и Android SDK 37 — они уже настроены в этом проекте.

## Что можно проверить

- Главное меню и настройки. Поделиться — открывает системное меню, поддержка — почтовый черновик, соглашение — страницу в браузере. Адрес поддержки пока не задан.
- Поиск по названию трека или исполнителю. Например: `The Beatles`, `Yesterday`, `Queen`. История появляется при нажатии на пустое поле.
- Любой неизвестный запрос показывает «Ничего не нашлось». Запрос `ошибка` или `error` показывает пример ошибки загрузки.
- Трек открывается в плеере. Кнопка воспроизведения запускает только таймер: аудиофайлов в моках пока нет.
- Избранное, создание плейлистов, выбор обложки и добавление треков в плейлист. Один трек нельзя добавить в один плейлист дважды.
- Избранное и плейлисты сохраняются на устройстве. Количество треков и длительность считаются по фактическому содержимому, поэтому числа могут отличаться от примеров в Figma.

Тёмная тема и удаление плейлистов/треков пока не реализованы.

## Где что лежит

- `MainActivity.kt` запускает приложение.
- `ui/PlaylistApp.kt` переключает экраны и обрабатывает кнопку «Назад».
- Остальные файлы в `ui` содержат экраны и общие элементы интерфейса.
- `data/Track.kt` содержит примеры треков и поиск по ним.
- `data/MusicLibrary.kt` хранит избранное и плейлисты, `data/SearchHistory.kt` — историю запросов. Для сохранения используется SharedPreferences.
- `res` содержит шрифты, обложки и иконки. Исходные SVG из Figma лежат в `assets/icons`, а их версии для Android — в `res/drawable`.

## Проверки

Сборка: `./gradlew :app:assembleDebug`

Проверка Android Lint: `./gradlew :app:lintDebug`

Проверки экранов на запущенном эмуляторе: `./gradlew :app:connectedDebugAndroidTest`

Автоматические проверки начинают с чистых данных приложения. Их изображения сохраняются в эмуляторе в `Pictures/PlaylistMaker`.
